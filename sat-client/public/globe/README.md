# Globe assets

These files are bundled locally so the primary 3D view does not depend on an image or GeoJSON CDN at runtime.

- `earth-dark.jpg` and `earth-topology.png` come from the example assets distributed with `three-globe` 2.45.2. The package is MIT licensed, copyright Vasco Asturiano.
- `countries.geojson` is the Natural Earth 1:110m countries dataset distributed with `three-globe`. Natural Earth data is public domain.
